# 证据采集 eval（stub）

> 触发条件：该 skill 被反复使用、需要质量闸时补全。当前精简优先，先 stub 不镀金。

## 验收要点（占位）

1. **归档可回溯**：证据原文是否存进 sources/ 并给可引用文件名？
2. **可靠度定级**：self/indirect/direct/data 是否据实填，evidenceLevel ≤ 上限？
3. **支持/反驳判定**：是否明确每条受影响假设是支持还是反驳，反驳触发循环状态机？
4. **不等于可开工**：单条支持证据是否被误读成"可以造了"？只要还有裸奔承重假设就停在回路内。
5. **盘点剩余裸奔**：收尾是否列出还剩哪些承重假设未测，而非宣布验证通过？

补全时参考 assumption-xray/eval.md 的写法（5 条 + ✅/❌ 对照）。
